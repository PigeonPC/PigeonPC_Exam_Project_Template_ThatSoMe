# ThatSoMe

This is a simple setup for a "Social media" application made with Node.js and Express for my Full-stack Node.js exam project.

### About

The idea is to create a simple social media platform, where you can create a profile, write and view status updates.

I use the word "social" quite liberally here, since to begin with, it will not actually be a social media platform.. But you will be able to fill in your profile, write status updates, and view your own updates on the dashboard.

**Possible future updates could be:**
- Friends
- Images
